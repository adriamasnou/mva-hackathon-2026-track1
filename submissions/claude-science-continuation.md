# Proposed use of $12,000 in Claude Science credits

**Conditional post-award plan · 24 October 2026 · no credits received or spent under this plan**

Our next computational deliverable would be an auditable system that links each MVA therapeutic claim to its primary evidence, identifies the experiment that could change the decision, and checks whether a claimed rescue survives exposure, proliferation and cell-fate controls. It builds on the delivered source audit, public validation, interpretation canary and functional-rescue decision prototype. A negative drug result would still leave reusable evidence and analysis tools.

The organizers designate first place as **$12,000 in Claude credits**, intended for Claude Science and continued computational work on MVA. The following allocations are **proposed credit-spending ceilings**, not provider quotes or guaranteed quantities of compute. This plan makes no allocation or commitment of cash-prize funds. Laboratory work is a separately costed, currently unfunded proposal.

## Six allocations, released by milestone

1. **$600 — qualify the service and measure actual cost.** Confirm the award's eligible services, model access, billing units, expiry, account arrangements and data terms. Freeze a small calibration set: 20 claim–source pairs and 10 public case mappings drawn by a recorded rule, including known extraction and interpretation failures. Measure billed credit use, citation/locator accuracy, reproducibility and human-review effort. Preserve all outputs and failures. Deliver a measured cost-per-reviewed-item estimate and a feasible workload forecast. No assumed token tariff or GPU conversion is used before the award's billing basis is confirmed.

2. **$3,600 — independent checks of the MVA evidence chain.** Use separate extraction and challenge passes against legally held primary articles, figures, supplements and published source data. Prioritize variant identity, competent versus total BubR1, exposure, functional outcomes and counterevidence. Every decision-bearing claim must have a source locator, evidence type, transfer limitation and resolved reviewer decision; unresolved disagreements remain visible. Extend the existing case-source review with a second review process that is blind to ranking outcomes. LLM agreement is not independent biological validation; expert adjudication remains a separate requirement. Deliver a versioned evidence graph and discrepancy ledger with machine-checkable provenance.

3. **$3,000 — stronger public-data validation.** Freeze a new evaluation protocol before inference, group related cases and repeated variants to prevent leakage, and separate source-label recovery from diagnostic truth. Use dated database snapshots and an explicitly documented temporal split only where the resource dates make it valid. Compare phenotype-aware, phenotype-free and prespecified simple baselines; report candidate counts, gene/family-clustered uncertainty, failures and sensitivity to disputed labels. Do not recycle the already-examined cohort as an untouched holdout. Deliver executable evaluation code, frozen manifests, ablations and a complete failure report; a negative comparison is a valid result.

4. **$2,400 — analyse the experiment before and after it runs.** Build on the existing rescue-decision prototype to simulate clustered cell measurements, missing follow-up, selective death/arrest, exposure uncertainty and multiple dose–time comparisons. Choose useful pilot precision and an efficient staged design; lock confirmatory rules after genuine pilot estimates are available. If a separately funded laboratory supplies authorized measurements, use credits for reproducible imaging/statistical analysis and blinded quality checks against human annotations. If no laboratory data arrive, deliver the tested analysis pipeline and identifiability report using public and explicitly synthetic data. Simulation cannot measure N1002K function or establish drug superiority.

5. **$1,200 — make the results usable beyond this case.** Package the evidence-checking and decision-analysis tools for offline reuse, with public examples, installation checks, provenance and failure demonstrations. Produce a clinician-facing evidence brief and a plain-language explanation of what each possible experimental outcome means. Test comprehension with prespecified tasks if consenting reviewers become available; otherwise report only software/document checks, not demonstrated patient or clinician impact. Keep MVA as the primary scientific use case.

6. **$1,200 — controlled reserve.** Hold for failed-run recovery, source updates, blinded challenge cases or an independent repeat of the most consequential analysis. Release only after a written reason, remaining-balance check and refreshed cost forecast. Unused credit is not a reason to run low-value analyses. This reserve does not imply access to external services or laboratory capacity.

**Total: $12,000 in proposed Claude Science credit ceilings.** Any additional Innovation Award credit is outside this base plan; neither an award nor combined redemption is assumed.

## Delivery schedule and stop rules

Time starts when credits are activated and their terms are confirmed. Target weeks 1–2 for service qualification; weeks 3–6 for the first evidence and validation release; weeks 7–10 for the experiment-analysis package; weeks 11–12 for a reproducible release and remaining-credit review. These are planning targets, not a provider-approved timetable. Replan if the actual expiry or measured throughput makes them infeasible.

Before each work package, record the question, inputs and hashes, planned outputs, acceptance checks, eligible service, model/version, credit ceiling and responsible reviewer. Reconcile actual billing after each batch and reserve headroom for in-flight requests. The pilot determines batch sizes; a budget dashboard alone is not a hard billing limit. Stop further dispatch at the package ceiling and use provider-enforced limits where available. No automatic paid overage or cash top-up is included.

Credits are released against verifiable artifacts, not a promised positive conclusion. A release fails review if it contains unsupported decision-bearing claims, untraceable case labels, undisclosed failed runs or conclusions stronger than the experiment. Report how many items remain unreviewed or disputed. A clean technical run does not prove clinical validity.

## Access and funding dependencies

The award description does not specify whether these credits redeem as API use, subscription/extra usage, hosted compute or a combination. Account eligibility, model availability, expiry, concurrent-job limits, storage/egress and third-party charges require the actual award terms. General Anthropic science-program terms are not substituted for the hackathon award agreement.

No paid laboratory, new clinical collaborator, patient-cell access or expert-review commitment is assumed. Credit-funded assistance can prepare specifications and analyse authorized results; it does not pay for reagents, laboratory labour, shipping, taxes, assay services, journal licences or clinical oversight unless the award explicitly includes an eligible service. Those costs remain separate.

The post-award programme uses public sources, shareable code and permitted findings. It does not depend on retaining the hackathon's controlled-access child dataset beyond its deletion deadline. Any new experimental data require appropriate permission and a compatible provider data-processing arrangement before use. No model training on the child's data is proposed.
