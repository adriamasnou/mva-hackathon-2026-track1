# Notes for judges

We propose arimoclomol for **conditional preclinical testing** in BUB1B-MVA. N1002K function is unmeasured; phase is inferred. Advancement requires functional rescue at relevant exposure, not merely more BubR1. Full-length abundance-matched controls, checkpoint and segregation measurements, and proliferation/selection safeguards make the proposal falsifiable. A fragment thermal assay alone cannot decide it.

The reusable contribution is implemented: an offline gene-to-condition navigator with per-gene provenance, explicit unmapped rows and source disagreements, plus a portable interpretation canary that fails when required output is absent. The navigator covers 2,063 dated register rows; eleven source-adjudicated tasks pass, with explicit evaluation limits. Real SpliceAI inference passes six controls; a separate harness self-test rejects nine injected failures.

No drug rescue, clinical efficacy or family usability study is claimed. The report distinguishes executed work from proposed experiments and provides the sources, code and limitations needed to assess each.
