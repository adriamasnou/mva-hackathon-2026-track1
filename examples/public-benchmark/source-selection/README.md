# Frozen public case selection

`frozen-cases.json` preserves the twelve-case selection and all four phenotype arms exactly as frozen before Exomiser inference. `selection-plan.json` specifies quotas, seed, eligibility and source archive hash. `prepare.py` can reconstruct the selection from the fixed public archive. Keep the upstream BSD-3-Clause license in `source/` with derived records.

This file records preparation, not an executed benchmark. The source-label and runtime limitations in the [evaluation recipe](../README.md) apply. The final public result includes separate truth-adjudication and execution records.

The twelve byte-identical source phenopackets are retained in `source/selected/`. To regenerate selection, copy this directory to a separate work directory and run `python3 prepare.py --download --output-dir /path/to/prepared-output` there. The fixed public archive is 11.6 MB. Adding `--reference /path/to/GRCh38.fna` verifies source REF strings against an indexed local reference. The archived preparation verified all fourteen; reference matching does not establish causality or phase.

Read [initial label adjudication](truth-adjudication.json) for PAX4 and the X-case boundaries. [Version 2](truth-adjudication-v2.json) preserves the initial nine-case main-text review. [Version 3](truth-adjudication-v3.json) adds the recovered MTOR article and supplements and the complete DOCK8 appendix. All nine main texts were read in available versions, including two online author-copy text renditions. Exact figure and supplement gaps remain explicit. These files contain our review and source locators, not redistributed publisher papers.

The [frozen source-support groups](source-support-groups-v3.json) retain both the initial 4/3/2 partition and the later 4/5 evidence map. Four cases have support for all selected positive HPO terms; five have material qualifications. MTOR includes a competing PKD1 explanation for renal findings, BCKDHB uses syndrome-level phenotypes, and several other cases have attribution or phenotype-specificity limits. Source-support groups are sensitivity descriptions, not clinical truth classes. No case or phenotype arm was replaced after these findings.

A later [X-case source review](x-case-source-review.md), also retained before inference, resolves the ZIC3 positive spleen-feature conflict as a cross-individual transcription and identifies a non-equivalent OFD1 exact-allele text/figure conflict. The [dated addendum](addendum-x-source-before-inference.json) retains these findings without changing any selected input, phenotype donor, primary case or source-support group. X-case rankings are technical observations, not validation of those source records.
